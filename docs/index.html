ASR 接口参考

普通话、粤语、英语语音识别服务。覆盖鉴权、文件上传、连续音频流、响应字段、错误处理，以及网页中录音与文本的对应保存。

流式识别已实测三语自动检测部分容器样本需转换单文件 HTML · 支持手机阅读

01服务概览

ASR 将语音转为文字；VAD 判断语音开始和结束。本文依据调用方约定、服务端 OpenAPI 与 2026-09-09 实测整理。服务端没有公开的参数和限制标为待确认。

HTTP 基础地址http://10.210.1.23:19003
流式识别地址ws://10.210.1.23:19003/infer/stream
建议请求并发8 · 请求方控制并发
文件上传单位每次请求 1 个音频文件

文件上传声明支持：wav、flac、mp3、mp4、mpeg、mpga、m4a、ogg、webm。这些是文件接口格式；流式接口只接受后文规定的原始 PCM。

当前可用性

WebSocket、/infer 与 /v1/audio/transcriptions 的基本转写均已成功。早期的文件请求 500 不能代表最新 WAV 状态；部分容器与参数组合仍会报错，详见格式与错误表。

02鉴权与网络

语种查询、文件识别和 WebSocket 握手使用相同的 Bearer API key。文档与代码仓库不包含真实密钥。

  • 服务位于内网，调用机器必须能路由到 10.210.1.23:19003。
  • curl 使用 --noproxy '*'，避免请求进入与内网不相通的代理。
  • 健康检查示例不需要 API key。/languages 缺少或错误凭据返回 HTTP 401。
  • WebSocket 缺少鉴权时，本轮观察到握手被 HTTP 403 拒绝。
  • 浏览器原生 WebSocket 构造函数不能设置任意 Authorization 请求头。本项目由 Node.js 服务代发鉴权请求，网页连接同源 /api/live。

生产环境按部署网络选择 HTTPS/WSS。文档中内网 HTTP/WS 地址按当前实际服务展示；没有证据表明该端口提供 TLS。

06WebSocket 流式识别

WSws://10.210.1.23:19003/infer/stream
握手 + 鉴权→start→started→PCM / partial→end / final

1. 音频规格

参数取值说明
编码pcm_s16le有符号 16 位小端整数
采样率16000 Hz每秒 16,000 个采样
声道1单声道
封装WebSocket binary 帧只发送 PCM 数据，不带 WAV 文件头，也不是 Base64 JSON

2. 发送启动消息

字段类型填写规则
typestring固定为 start
session_idstring1–128 个英文字母、数字、下划线或连字符；同一时刻不能重用活动 ID；结束后可复用，但新连接从头识别

音频字段各自的默认行为没有公开。本接入规范要求全部显式填写；省略全部音频字段、使用 48 kHz、双声道或 mp3 均已观察到 invalid_audio_format。不要追加未公开字段，chunk_seconds=1 或 0.5 已被拒绝。

3. 等待 started 后持续发送音频

收到确认后发送二进制 PCM。服务默认每累积 2 秒音频产生一次中间文字，未验证到可通过客户端缩短此周期的配置。实时验证 60.0 秒成功、60.1 秒返回 audio_limit；连续录音应提前创建下一段。过快灌入音频会触发 overloaded，应按实时速度发送。

4. 发送结束消息并等待最终文字

麦克风停止或 VAD 判定当前语音结束时，先发送缓冲区剩余 PCM，再发送 end。保持连接直至收到 final；直接关闭连接可能丢失尾段文字。结束控制消息是 end，发送 finish 已实测被拒绝。

每次用新 text 替换该段暂定文字。不要将多个 partial.text 直接拼接，否则前文会重复。final 到达后固定该段；不同会话按录音开始时间排序，不按网络返回先后排序。

空音频 end 返回 sequence=0、audio_seconds=0、language=""、text="" 的 final。5 秒全零 PCM 与 10 秒纯高斯噪声也未识别出文字。收到 final 不等于存在有效语音。

重复 ID 与续传

同一活动 ID 的第二个连接被 session_conflict 拒绝。结束后可复用 ID，但返回新的 request_id，sequence/audio_seconds 从新音频计算。关闭 3 秒英语前缀后，同 ID 重连发送粤语只识别了新音频；resume 字段被拒绝。这不能证明存档幂等或避免重复保存。

并发与配额

同步启动的 8 路实时语音均获得 final，首次文字约 2.09–2.23 秒。另有 9 个仅完成 start 的空会话被同时接受；这不是 9 路推理压力测试，也不证明最大推理配额。建议并发仍为 8。

错误表不是内部所有代码的穷尽清单。HTTP 文件处理的服务器超时尚未触发，测试脚本的客户端超时不能视为服务器超时。静音 PCM 仍是应用消息，不等同于完全不发送消息。

12网页与 VAD 接入

麦克风→PCM 重采样→原 ONNX VAD→ASR WebSocket→文字 + 文件
  • 前端使用 AudioWorklet 持续采集，将浏览器采样率转换为 16 kHz 单声道 PCM，每 100 ms 发送一帧。
  • Node.js 运行用户提供的 vad-new-standalone/materials/net.onnx，移植其 80 维 fbank、缓存预热和语音起止判定。
  • VAD 检测到说话时取回预留音频，建立 ASR 会话；停顿后发送 end。网页默认停顿阈值为 600 ms，可通过 VAD_SILENCE_MS 调整；原工程默认值为 300 ms。
  • 长句在 55 秒前切换 ASR 会话，避免到达服务声明的 60 秒上限。新段保持时间顺序。
  • 每个 VAD 语音段独立自动检测语种，分段切换三语已通过。句内混语的 HTTP 与 WS 结果出现差异，详见实测章节；响应仅提供一个 language 标签。
  • 本地服务对上游设置最多 8 个活动会话，并对消息大小和积压音频设置上限。发生错误时停止采集并保留已保存内容。
手机访问

HTML 文档可直接在手机浏览器打开。网页录音需要安全上下文：本机 localhost 可用；手机通过局域网 IP 访问应用时，需要 HTTPS 和手机信任的证书。服务必须运行在能访问 ASR 内网的机器上，录音时保持页面在前台。

浏览器依据：MDN · getUserMedia、MDN · AudioWorklet、MDN · WebSocket 构造函数。

13音频与文本对应保存

此节说明本项目的本地应用行为，不是远端 ASR 已公开的存档协议。每次点击“开始录音”创建独立目录；完整音频保留静音，每个 VAD 片段另存一组同编号音频与文本。

001.wav 与 001.txt 对应，002.wav 与 002.txt 对应。下载文件名前会附加录音编号，避免不同录音之间同名混淆。manifest 包含每段的开始与结束位置、语种、识别状态及音频和文本相对路径。

  • 完整 recording.wav 与 transcript.txt 对应本次连续录音；分段文件对应具体语音。
  • partial 更新暂定文本文件，final 到达后以最终文本覆盖；未完成的分段文本带有明确标记。
  • 文件写入本地服务磁盘，不只保存在网页内存。刷新页面后可从“已保存的录音”下载。
  • 写入中的 WAV 使用 .part 后缀，结束时修正文件头并转为 .wav；服务重新启动会尝试恢复遗留录音。
  • 默认保存在项目 recordings/，可通过 RECORDINGS_DIR 更改。录音、密钥和本地证书被 Git 忽略。

真人语音与人工噪声

采用 Google FLEURS 的 cmn_hans_cn、yue_hant_hk、en_us 各 1 条真人录音，分别生成整段 RMS 定义的 20、10、0 dB 高斯噪声版本，共 12 条，语种标签均正确。人工噪声不能代表真实街道、会议室或多人串音。

样本 / 指标原音20 dB10 dB0 dB
普通话 / CER0.0%0.0%0.0%4.5%
粤语 / CER5.3%5.3%5.3%5.3%
英语 / WER0.0%0.0%13.3%13.3%

CER/WER：NFKC、英文小写；中文繁转简并去标点/空白；英文按词比较；不展开数字或缩写。粤语 5.3% 来自 40/四十，英语 13.3% 来自 you are/you’re 形式差异。普通话 0 dB 的“宗派→宗教”“或→和”是实质错词。原始误差不能直接当作语义准确率。

句内混语对照

此样本的 WS 漏掉开头普通话，HTTP 保留三语内容。句内混语仍可能丢词；“支持三种语言”不能推导为所有流式混语可靠。VAD 停顿分段后连续切换三语已通过。

VAD 噪声边界

真人及噪声版本均检测到语音，但片段数随噪声变化；纯高斯噪声也误触发 1 段。ASR 对纯噪声返回空文字，网页会标记未识别出文字并保留音频。不能承诺所有背景噪声下零误触。

  • 真实最大上传体积、文件时长和 HTTP 服务端超时：已通过 16 MiB / 120 秒，但未触发真实上限。
  • 远端存档、保存目录、保留周期、删除机制及存档幂等：需要源码、部署配置或日志。
  • 全局推理配额、远端资源曲线及数小时/数天稳定性。
  • 真实 iPhone/Android 型号的麦克风、后台/锁屏、网络切换，以及真实复杂环境噪声：尚无真机验证。
  • 未公开参数与内部错误码的穷尽清单：本页只将有证据的行为作为可依赖契约。

01服务与鉴权

正式环境基础地址：

公网 https://api-gai-volc.sensetime.com/agent-5o/signpost/v0/prod-agent-5o-sensenova-filabs-asr-v1

内网 https://api-gai-volc-internal.sensetime.com/agent-5o/signpost/v0/prod-agent-5o-sensenova-filabs-asr-v1

路由拼在基础地址路径之后：文件识别 /infer，流式识别 /infer/stream（协议改为 wss）。公网请求使用 Authorization: Bearer <API_KEY>，两个识别入口都必须传授权的 app_id，由商汤语音组签发。建议并发 8，一次离线请求只上传一个文件。

浏览器连接本项目同源 /api/live，Node.js 代发鉴权。密钥和 app_id 仅保存在服务端环境变量，不能放入网页、示例或公开仓库。

02流式请求

鉴权握手→start→started→实时 PCM→end→末段结果与连接结束

一段音频使用一条连接和一个 session_id。连接建立后 10 秒内发送 start，收到 started 后才发送二进制音频：

参数类型与默认值说明
session_idstring，必填1–128 位字母、数字、下划线和连字符；并发请求使用不同 ID
format / sample_rate / channels必填仅 pcm_s16le / 16000 / 1
server_vadboolean，true服务端语音截断；建议开启，关闭可能导致过长语音错误
vad_intervalinteger，800静音截断阈值，100–2000 毫秒
traditionboolean，false是否将输出转换为繁体；false 表示不要求繁体转换
gainnumber，1.0线性音频增益；大于 1 放大，0–1 衰减，本项目只接受有限正数

itn、punctuation、context 在源文档中标为 TODO，本项目不发送这些字段，也不承诺相应效果。

音频为 16 kHz、单声道、PCM16 小端原始字节，不含 WAV 头、Base64 或 JSON。推荐每包 100 ms，即 3200 字节。尾包不足 100 ms 时发送实际字节，不补静音。按实时速度发包，同时持续接收结果；超速发送会收到错误码 401。启动预留音频也必须限速，不能在 started 后一次灌入。

音频发完，队列排空后发送一次 {"type":"end"}，并保持连接接收剩余结果。

03响应与完成

所有响应都是 JSON 文本消息。started 返回 chunk_seconds 和 max_audio_seconds，流式时长以该连接声明为准。

一个 VAD final 不表示整条连接已结束。 partial.text 是当前 VAD 段的累计假设，每次替换；final.text 固定该段，所有 final 按顺序保留。后续 partial 不得覆盖前面已完成的文字。

字段含义
sequence下发结果序号；过滤重复与过期结果；final 可以与前一 partial 共用序号
session_id / request_id客户端会话 ID / 服务端追踪 ID
start_audio_seconds当前 VAD 段起点，单位秒
audio_seconds当前结果覆盖的音频时间；final 中为该 VAD 段尾点
language / text识别语种 / 当前段文本
code / message仅 error 消息存在的错误码与详情

客户端发完 end 后，继续接收尾段 final，直至服务端 end 或正常关闭连接。本项目至少收到一个 final 才算成功；提前断开、异常关闭或缺少 final 会报告该段失败，并保留音频供离线补救。

04离线识别

POST 基础地址/infer，使用 multipart/form-data 上传完整文件，不需要 session_id。

位置字段要求
HeaderAuthorizationBearer <API_KEY>
Formaudio必填，音频文件
Formapp_id必填，授权的 APP ID
Formlanguage可选，语种全称或缩写；省略自动检测
Formtradition可选，true / false，默认 false

新版文档声明支持 wav、flac、mp3、mp4、mpeg、mpga、m4a、ogg、webm，单次默认最长 60 秒。本项目用保存的 PCM16 WAV 做重识别；其他容器未在本次逐一验证。无效密钥为 HTTP 401，不支持语种为 400，未授权 app_id 为 403。

05错误处理

code文档含义
101–107消息、start、音频格式、语种、音频数据、APP ID 缺失或不支持字段
201 / 202APP ID 未授权 / 其他鉴权失败
301 / 302会话冲突 / 连接数超限
401 / 402流式发送过快 / 重复发送 end
501–504推理错误、超时、后端或其他内部错误

本项目兼容数字与字符串错误码，保存 code 用于诊断；不把上游内部错误详情或凭据发给浏览器。单个识别段失败会继续录音，并用保存的 WAV 重识别。麦克风、浏览器连接或磁盘故障属于会话级错误，会停止录音。

06调用示例

完整 TypeScript 示例在 docs/examples/stream.ts，支持授权 app_id、服务端 VAD、繁体与增益，按实时速度发送，并接收全部 final。

07网页与 VAD

AudioWorklet 将麦克风音频重采样为 16 kHz PCM16，每 100 ms 发给本地 Node.js 服务。原 ONNX VAD 控制语音指示、本地分段与音频保存，预留音频避免截断句首；上游 server_vad 则在单条连接内截断语音并返回多个 final。

本地静音阈值 VAD_SILENCE_MS=600；上游阈值 ASR_VAD_INTERVAL_MS=800。上游默认开启 ASR_SERVER_VAD=1，增益 ASR_GAIN=1。本地长段默认 55 秒内旋转，并跟随 started 宣告的更短限制。

录音前可锁定语种并选择“默认文字”或“繁体中文”。后者同时传给流式 start 和离线表单，保存在 requestedTradition。默认文字表示不请求繁体转换。录音进行中和结束处理中不能修改。

分段结束后用保存的 WAV 再调用离线接口，补全标点并恢复流式失败的文本；等待预算按音频长度取 10–40 秒。网页停止后的等待窗口为 75 秒。

08保存与下载

每次录音保存完整 recording.wav、transcript.txt、manifest.json，以及 segments/ 下同编号 WAV/TXT。完整音频保留静音；每段文字对应实际保存的语音段。多个上游 VAD final 合并到所属本地段，离线重识别可更新其最终文字。

本地路径用途
GET /api/statusVAD、配置、上游健康、活动会话数及 VAD 设置
WS /api/livestart（可带 language、tradition），ready 后发送 PCM，最后 end
GET /api/recordings最近 50 条录音清单
GET /api/recordings/{id}/audio 或 text 或 manifest完整音频、文字和清单下载
GET /api/recordings/{id}/segments/{n}/audio 或 text对应分段音频与文字下载
DELETE /api/recordingsJSON {"ids":[...] }，需同源 Origin；只删除用户确认的已结束录音

本地文本事件为所属段的累计快照，以 id 更新；与上游按 VAD 段返回的事件含义不同。浏览器收到 stopped 表示本次保存与识别处理完成。历史记录保存在独立目录，代码更新不删除录音。

09验证范围

2026-10-10 公网探测已验证同一连接返回两段粤语 VAD final、带起止时间、繁体文字和正常完成。自动测试覆盖启动缓冲限速、尾包精确字节、多 final 汇总、重复序号、partial/final 共用序号、end 去重、缺少 final、异常断开及数字错误码。

npm run test:live 用仓库语音样本验证普通话、粤语、英语、连续切换语种与粤语默认/繁体输出，同时核对完整 PCM 与下载内容逐字节一致、分段 TXT 与最终文字一致。指定 ASR_TEST_APP_URL 可直接复测运行中的部署。

精简验证证据见 tests/evidence/upstream-0930.json；9 月证据保留作历史对照。测试不代表总体准确率，也未覆盖全部音频容器、真实手机录音或复杂噪声环境。
